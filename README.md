# Cirrus Map
Mind mapping is a way to organise your thoughts and plan large tasks.
Current mind mapping software available is limited, ugly, and subscription based. Cirrus map will be a pleasure to look at and to use. 

## Approach
Cirrus map is made using C++ and the QT library

## Status
In development

![A mind map for birthday party planning](https://ruthevans.co.uk/images/cirrusmap01.png)

### Next Features
- Ability to delete maps
- Cloud nodes painting order preservation
- Group select nodes
- Gracefully curved lines for node connections

Build with QT creator
